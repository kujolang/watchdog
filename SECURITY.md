# Security Policy

## Supported Versions

Security fixes are applied to the active main branch.

| Version | Supported |
| --- | --- |
| main | yes |
| older tags | no |

## Reporting A Vulnerability

Please do not open public issues for suspected vulnerabilities.

Preferred reporting channels:

1. GitHub Security Advisory for this repository.
2. Direct email to me@robertdevore.com with subject line `watchdog security report`.

Please include:

- affected endpoint or component
- reproduction steps and minimal payload
- observed impact
- suggested mitigations if known

## Response Targets

- Initial acknowledgement: within 2 business days.
- Triage decision: within 5 business days.
- Mitigation plan or patch timeline: within 10 business days for confirmed issues.

## Disclosure Policy

- Reports are handled privately until remediation is available.
- Coordinated disclosure is preferred.
- Credit is provided in release notes unless anonymity is requested.
